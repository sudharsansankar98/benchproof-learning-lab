# Day 01 — Scientific Data Basics

## Project
BenchProof: Scientific Research Quality Control

## Today's objective
Learn how sample size and mean are calculated from experimental data.

## Example dataset
Control group measurements: 10, 12, 14, 16, 18

## Manual calculations
- Sample size (n): 5
- Sum of observations: 70
- Mean: 70 / 5 = 14

## Why this matters
Scientific reports should present sample sizes and summary statistics that are consistent with the underlying experimental data.

## Validation rule
The reported sample size should match the number of observations supplied.
